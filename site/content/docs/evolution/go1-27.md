**Août 2026.** Les méthodes génériques, un nouveau moteur JSON, et un package
`uuid` standard.

## Langage

- **Les méthodes génériques** : une méthode peut déclarer ses propres
  paramètres de type. C'était l'une des limites les plus visibles des
  génériques depuis Go 1.18 :

  ```go
  func (l Liste[T]) Transforme[U any](f func(T) U) Liste[U] { … }

  carres := l.Transforme(func(n int) string { return strconv.Itoa(n * n) })
  ```

  Une méthode générique ne peut cependant pas implémenter une méthode
  d'interface.

- Dans un **littéral de structure**, un champ promu par intégration peut
  servir de clé : `Chien{Nom: "Rex", Race: "berger"}`.
- L'inférence de type s'applique partout où une fonction générique est
  affectée ou convertie en un type fonction.

## JSON : encoding/json/v2

Le package **`encoding/json/v2`** et son compagnon **`encoding/json/jsontext`**
rejoignent la bibliothèque standard. Plus stricte par défaut (noms exacts,
doublons et UTF-8 invalide refusés), la v2 est aussi bien plus rapide au
décodage.

`encoding/json` est désormais **réimplémenté au-dessus de la v2** : tous les
programmes existants profitent du gain de performance, sans modification.

## Nouveaux packages

- **`uuid`** : génération (`New`, `NewV7`…) et analyse d'UUID.
- **`crypto/mldsa`** : les signatures post-quantiques ML-DSA (FIPS 204).
- `simd` (expérimental) : des types vectoriels portables.

## Runtime

- Les **petites allocations** (moins de 80 octets) sont jusqu'à 30 % moins
  coûteuses.
- Le **profil de fuites de goroutines** (`goroutineleak`) est disponible par
  défaut dans `runtime/pprof` et `net/http/pprof`.
- Les traces de panique affichent les **labels pprof** des goroutines.
- Les channels des timers sont toujours non bufferisés : l'ancien comportement
  n'est plus disponible.

## Bibliothèque standard

- `strings.CutLast` et `bytes.CutLast`.
- `synctest.Sleep` et `httptest.NewTestServer`, qui utilise un réseau simulé
  en mémoire.
- `rand.Rand.N`, la première méthode générique de la bibliothèque standard.
- `url.URL.Clone` et `url.Values.Clone`.
- Le serveur HTTP/2 respecte les priorités des clients (RFC 9218).
- Unicode 17.

## Outils

- `go doc` accepte une version (`go doc exemple.com/pkg@v1.2.3`), et l'option
  `-ex` affiche les exemples exécutables.
- `go mod tidy` regroupe les dépendances en deux blocs `require`, l'un direct
  et l'autre indirect.
- Nouveaux modernizers pour `go fix`.
- macOS 13 Ventura est désormais la version minimale.

## À retenir

Go 1.27 complète les génériques et modernise JSON, deux attentes de longue
date. C'est la version décrite dans ce livre. Voir les chapitres
[Génériques](../../langage/generiques/) et [JSON](../../bibliotheque/json/).
