**Février 2020.** Des goroutines vraiment préemptives et des modules prêts
pour la production.

## Langage

Une interface peut intégrer d'autres interfaces dont les méthodes se
**chevauchent** :

```go
type ReadWriteCloser interface {
	io.ReadCloser
	io.WriteCloser // Close apparaît deux fois : accepté depuis Go 1.14
}
```

## Runtime

- **Préemption asynchrone** : une goroutine qui exécute une boucle sans appel
  de fonction peut désormais être interrompue par l'ordonnanceur. Avant, une
  telle boucle pouvait bloquer le ramasse-miettes, voire tout le programme.
- **`defer` devient presque gratuit** : dans la plupart des cas, son coût est
  quasi nul. Il n'y a plus de raison de l'éviter pour des raisons de
  performance.
- Les timers sont réimplémentés et passent mieux à l'échelle.

## Outils

- Le support des modules est déclaré **prêt pour la production**.
- Un répertoire `vendor/` est utilisé automatiquement s'il est cohérent avec
  `go.mod`.

## Bibliothèque standard

- `hash/maphash` fournit une fonction de hachage rapide pour les chaînes et
  les octets.
- `t.Cleanup` enregistre une fonction de nettoyage à exécuter à la fin d'un
  test.

## À retenir

Depuis Go 1.14, on utilise `defer` sans arrière-pensée, et une goroutine ne
peut plus monopoliser un processeur.
