# Chapitre IV.14 — Go 1.23

**Août 2024.** Les itérateurs entrent dans le langage.

## range sur des fonctions

`range` accepte des fonctions de la forme `func(yield func(V) bool)`. N'importe
quelle structure de données peut ainsi être parcourue avec une boucle `for`
ordinaire, avec `break` et `return` :

```go
func Pairs(max int) iter.Seq[int] {
	return func(yield func(int) bool) {
		for i := 0; i <= max; i += 2 {
			if !yield(i) {
				return
			}
		}
	}
}

for n := range Pairs(10) {
	fmt.Println(n)
}
```

Le nouveau package **`iter`** définit les types `iter.Seq[V]` et
`iter.Seq2[K, V]`, ainsi que `iter.Pull` pour convertir un itérateur en
fonction « suivant ».

## Des itérateurs partout

Les packages `slices` et `maps` gagnent des fonctions qui produisent ou
consomment des itérateurs : `slices.All`, `slices.Values`,
`slices.Backward`, `slices.Collect`, `slices.Sorted`, `slices.Chunk`,
`maps.Keys`, `maps.Values`, `maps.All`, `maps.Collect`…

```go
cles := slices.Sorted(maps.Keys(m))
```

## Nouveaux packages

- **`unique`** : l'*internement* de valeurs. `unique.Make(v)` renvoie un
  identifiant ; deux valeurs égales donnent le même identifiant, comparable en
  temps constant.
- **`structs`** : `structs.HostLayout` indique qu'une structure doit suivre la
  disposition mémoire de la plateforme, pour l'interopérabilité avec le C.

## Les timers

- Les `time.Timer` et `time.Ticker` qui ne sont plus référencés sont libérés
  par le GC, même sans appel à `Stop`.
- Leurs channels deviennent non bufferisés : après `Stop` ou `Reset`, aucune
  valeur périmée ne peut plus être reçue.

## Outils

- **Télémétrie** : l'outil `go` peut collecter des statistiques d'usage
  anonymes, sur consentement explicite (`go telemetry on`).
- `go vet` signale l'utilisation de fonctions plus récentes que la version de
  Go déclarée dans `go.mod`.
- `os.CopyFS` copie un `fs.FS` sur le disque.

## Aperçu : les alias génériques

`GOEXPERIMENT=aliastypeparams` permet de tester les alias de types génériques,
finalisés en Go 1.24.
