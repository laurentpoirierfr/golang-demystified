# Chapitre IV.7 — Go 1.16

**Février 2021.** Les fichiers embarqués, les systèmes de fichiers abstraits,
et les modules par défaut.

## Embarquer des fichiers : embed

La directive `//go:embed` intègre des fichiers dans l'exécutable à la
compilation :

```go
import "embed"

//go:embed templates/*.html
var gabarits embed.FS

//go:embed version.txt
var version string
```

Un service web peut ainsi être livré en un seul binaire, avec ses gabarits,
ses fichiers statiques et ses migrations SQL. Il n'est plus nécessaire
d'utiliser des outils externes comme packr ou statik.

## io/fs

L'interface `fs.FS` représente un système de fichiers en lecture seule. Elle
est implémentée par `embed.FS`, `os.DirFS`, `zip.Reader` et
`testing/fstest.MapFS`, et acceptée par `http.FS`, `template.ParseFS`, etc.

## Les modules par défaut

- `GO111MODULE=on` devient la valeur par défaut : le mode module est actif
  partout.
- `go install outil@version` installe un exécutable sans modifier le
  `go.mod` du projet courant.
- La directive `retract` permet à un auteur de signaler qu'une version publiée
  ne doit pas être utilisée.

## Apple Silicon

Le port `darwin/arm64` prend en charge les Mac à processeur Apple M1.

## Bibliothèque standard

- Le package **`io/ioutil` est déprécié** : ses fonctions sont déplacées dans
  `io` et `os` (`io.ReadAll`, `os.ReadFile`, `os.WriteFile`, `os.ReadDir`…).
- `signal.NotifyContext` crée un contexte annulé à la réception d'un signal.
- `runtime/metrics` expose les métriques du runtime de façon stable.

## À retenir

`embed`, `io/fs` et `os.ReadFile` sont aujourd'hui des outils de base. Voir le
chapitre [Fichiers et flux](../../bibliotheque/fichiers/).
