**Août 2025.** Aucun changement de langage, mais un runtime mieux adapté aux
conteneurs et de nouveaux outils de test et de diagnostic.

## Runtime

- **`GOMAXPROCS` tient compte des conteneurs** : sur Linux, sa valeur par
  défaut respecte la limite de CPU du cgroup, et elle est ajustée si cette
  limite change. Un service limité à 2 CPU sur une machine de 64 cœurs ne crée
  plus 64 threads actifs.
- Le **ramasse-miettes Green Tea** est disponible en expérience
  (`GOEXPERIMENT=greenteagc`), avec 10 à 40 % de temps de GC en moins.
- Le **flight recorder** (`trace.FlightRecorder`) conserve en mémoire les
  dernières secondes de trace d'exécution, à enregistrer lorsqu'un incident se
  produit.

## Bibliothèque standard

- **`testing/synctest`** est finalisé : il teste du code concurrent dans une
  bulle dont l'horloge est virtuelle.
- **`sync.WaitGroup.Go`** lance une goroutine et la compte en une ligne :

  ```go
  var wg sync.WaitGroup
  for _, url := range urls {
  	wg.Go(func() { telecharge(url) })
  }
  wg.Wait()
  ```

- `http.CrossOriginProtection` protège contre les attaques CSRF.
- `encoding/json/v2` est disponible en expérience (`GOEXPERIMENT=jsonv2`).
- `os.Root` gagne de nombreuses méthodes (`ReadFile`, `WriteFile`,
  `MkdirAll`, `RemoveAll`, `Rename`…).
- `t.Attr` et `t.Output` pour les tests, `reflect.TypeAssert`, `slog.GroupAttrs`.

## Outils

- `go doc -http` ouvre la documentation dans le navigateur.
- La directive **`ignore`** de `go.mod` exclut des répertoires des motifs comme
  `./...`.
- Nouveaux analyseurs `go vet` : `waitgroup` (appel mal placé à
  `WaitGroup.Add`) et `hostport` (adresses construites avec `Sprintf`,
  incompatibles avec IPv6).

## Compilateur

Une correction de bug rend les déréférencements de pointeurs nil plus stricts.
Ce code, incorrect, fonctionnait par accident depuis Go 1.21 :

```go
f, err := os.Open("absent")
nom := f.Name() // panique désormais, comme il se doit
if err != nil {
	return
}
```

Testez toujours l'erreur **avant** d'utiliser les autres valeurs renvoyées.

## À retenir

Pour un service déployé dans Kubernetes, passer à Go 1.25 règle d'office
`GOMAXPROCS` correctement. Voir le chapitre
[Goroutines et channels](../../langage/concurrence/) pour `WaitGroup.Go`, et
[Tests](../../bibliotheque/testing/) pour `synctest`.
