**Février 2026.** `new` accepte une expression, le GC Green Tea devient la
norme, et `go fix` modernise le code.

## Langage

- **`new(expr)`** crée une variable initialisée avec la valeur d'une
  expression. Fini les fonctions utilitaires `ptr(v)` pour les champs
  optionnels :

  ```go
  u := Utilisateur{
  	Nom: "Alice",
  	Age: new(anneesDepuis(naissance)),
  }
  ```

- Un type générique peut se **référencer lui-même** dans ses contraintes :

  ```go
  type Additionnable[A Additionnable[A]] interface {
  	Ajoute(A) A
  }
  ```

## Runtime

- Le **ramasse-miettes Green Tea** est activé par défaut : 10 à 40 % de temps
  de GC en moins sur des programmes réels, et environ 10 % de plus sur les
  processeurs récents grâce aux instructions vectorielles.
- Les appels cgo sont environ 30 % plus rapides.
- L'adresse de base du tas est rendue aléatoire, pour renforcer la sécurité.
- Un profil expérimental détecte les **fuites de goroutines**.

## Outils : go fix renaît

`go fix` est réécrit sur le framework d'analyse de `go vet`. Il regroupe des
**modernizers** qui mettent le code à jour automatiquement : `interface{}`
devient `any`, une boucle classique devient `range` sur un entier,
`errors.As` devient `errors.AsType`, les copies de variables de boucle
disparaissent… La directive `//go:fix inline` permet à une bibliothèque de
faire migrer automatiquement les appels à une fonction obsolète.

```bash
go fix -diff ./...   # voir les modifications
go fix ./...         # les appliquer
```

## Bibliothèque standard

- **`errors.AsType`**, une version générique et plus sûre de `errors.As`.
- `slog.NewMultiHandler` diffuse les messages vers plusieurs handlers.
- `io.ReadAll` est environ deux fois plus rapide.
- `bytes.Buffer.Peek`, `netip.Prefix.Compare`, itérateurs de `reflect`
  (`Type.Fields`, `Type.Methods`…).
- `t.ArtifactDir()` range les fichiers produits par un test.
- `crypto/hpke` (chiffrement hybride à clé publique) et échanges de clés
  post-quantiques hybrides activés par défaut dans TLS.
- `image/jpeg` est réécrit, plus rapide et plus précis.
