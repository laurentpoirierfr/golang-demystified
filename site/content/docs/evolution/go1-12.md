# Chapitre IV.3 — Go 1.12

**Février 2019.** Une version de consolidation, centrée sur les modules, les
outils et la sécurité.

## Outils

- **`go vet` est réécrit** sur le framework `golang.org/x/tools/go/analysis`.
  Les analyseurs deviennent des composants réutilisables par d'autres outils,
  comme [gopls](https://pkg.go.dev/golang.org/x/tools/gopls) ou [staticcheck](https://staticcheck.dev). L'ancienne commande `go tool vet` disparaît.
- Les commandes `go` fonctionnent en mode module même hors d'un module, par
  exemple pour `go get` d'un outil.
- La directive `go` de `go.mod` indique la version du langage utilisée par le
  module.

## Bibliothèque standard

- **TLS 1.3** est disponible dans `crypto/tls`, sur option
  (`GODEBUG=tls13=1`).
- `strings.ReplaceAll` et `bytes.ReplaceAll`.
- `fmt` affiche désormais les maps **triées par clé**, ce qui rend les
  sorties reproductibles et facilite les tests.

## Runtime

- Sur Linux, le runtime rend la mémoire inutilisée au système de manière plus
  efficace.
- Les performances du GC sont améliorées lorsqu'une grande partie du tas reste
  allouée.

## À retenir

L'affichage trié des maps par `fmt` date de cette version : c'est ce qui
permet aux exemples de ce livre d'afficher des maps de façon stable.
