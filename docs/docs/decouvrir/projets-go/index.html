Les grands projets écrits en Go

Go s’est imposé comme le langage de l’infrastructure : une grande partie des outils qui font fonctionner le cloud, les conteneurs et l’observabilité est écrite en Go. Ses qualités y sont décisives : des exécutables statiques faciles à déployer, une concurrence intégrée pour les services réseau, des performances proches du C pour une fraction de sa complexité, et une compilation croisée triviale.

Ce chapitre présente quelques-uns de ces projets. Les lire est une excellente façon d’apprendre : leur code est ouvert, et souvent exemplaire.

Ce que ces projets ont en commun

Ces projets illustrent les points forts de Go mieux qu’un long discours :

  • ce sont souvent des services réseau (proxys, serveurs DNS, bases distribuées) : les goroutines et la bibliothèque net/http y font merveille ;
  • ils se distribuent en un seul exécutable, sans machine virtuelle ni bibliothèque partagée : kubectl, terraform ou hugo s’installent en copiant un fichier ;
  • ils sont compilés pour toutes les plateformes depuis une même machine, grâce à la compilation croisée ;
  • ils sont développés par des équipes nombreuses, parfois des milliers de contributeurs : la simplicité du langage et l’outillage commun (gofmt, go vet, go test) rendent leur code lisible par tous.

Plusieurs chapitres de ce livre s’inspirent directement de ces projets : la ligne de commande avec cobra (utilisé par Kubernetes, Hugo et GitHub CLI), les tests avec Testcontainers, ou les opérateurs Kubernetes.
